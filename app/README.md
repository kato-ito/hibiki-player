# Hibiki Player - 打包说明

把单文件网页应用（已拆分到独立仓库 [hibiki-player-web](https://github.com/kato-ito/hibiki-player-web)）封装为 Electron 桌面应用，并打包为 Windows 安装程序。

## 产物

- `dist/Hibiki Player Setup 2.15.1.exe` — NSIS 安装程序（x64），拷贝到其他 Windows 10/11 电脑双击即可安装
- `dist/win-unpacked/` — 免安装版，整个文件夹拷走即可直接运行 `Hibiki Player.exe`

安装后功能与网页版一致：麦克风实时可视化、音频文件/文件夹歌单播放、波形/频谱/声谱图/声场四种视图、界面皮肤切换与自定义背景图；此外桌面版独有杜比/DTS 等编码的解码播放（见下）。
麦克风权限已在 `main.js` 中预先放行，无需浏览器设置。

## v2.14.0 新增

**B 站扫码登录（效仿 bilidown 的实现方式）**

- 「⏬ B站下载」面板新增账号状态行：📱 扫码登录 / 退出登录，登录后显示 头像 / 用户名 / 大会员标识 / 等级
- 扫码登录流程与 bilidown 一致：调用 `passport.bilibili.com/x/passport-login/web/qrcode/generate` 获取登录 URL → **二维码在本地渲染进程绘制**（内置 MIT 库 qrcode-generator，不经任何外部图片服务）→ 每 2.5 秒轮询 `qrcode/poll`（86101 等待 / 86090 已扫码 / 86038 失效 / 0 成功）→ 解析跨域回调 URL 中的 Cookie
- 登录后自动解锁会员音质：解析视频即可选择 Hi-Res 无损 FLAC / 杜比全景声 E-AC3（登录后自动刷新音质清单）
- 启动时自动用本地保存的 Cookie 恢复登录状态（`nav` 接口校验），失效自动回到游客态
- **隐私承诺（数据只存本地）**：登录信息仅写入本机 `userData/bili-cookie.txt`（明文，与 bilidown 存入本机 Electron cookie 库同级别保护），只会随请求发送到 B 站官方域名（`*.bilibili.com`：view / playurl / nav / passport 登录接口与官方 CDN），程序内无任何遥测、统计或第三方上报端点；退出登录即删除本地文件
- 手动 Cookie 输入仍保留（登录后自动回填便于查看/备份），「高级」折叠区可见

## 文件结构

- `main.js` — Electron 主进程：创建窗口、放行麦克风权限
- `dolby-ipc.js` — 杜比/DTS 转码 IPC（`dolby:convert`：ffmpeg → PCM，含临时目录缓存与退出清理；`dolby:probe`：ffmpeg 读流信息兜底探测采样率）
- `preload.js` — 渲染进程桥：向页面暴露 `window.dolby.convert(file)` / `window.dolby.probe(file)`
- `verify-dolby.js` — 杜比链路端到端验证：真实 preload + 渲染代码走完 转码→播放（`npx electron verify-dolby.js <某.ac3>`）
- `fs-ipc.js` — 已保存歌单的文件读取桥（`fs:read`：凭保存的绝对路径懒加载音频）
- `verify-playlist.js` — 歌单保存链路端到端验证：新建→跨文件夹追加→保存→重启恢复→懒加载播放→缺失标注→删除（`npx electron verify-playlist.js`）
- `verify-interactions.js` — 交互功能端到端验证：播放/暂停/继续 · 长按拖动排序（含未长按反例）· 空歌单保存说明（`npx electron verify-interactions.js`）
- `verify-samplerate.js` — 采样率自适应端到端验证：44.1k/96k/192k/8k 逐个播放断言上下文与表头上限 · AC3 转码保留采样率 · detectRate 七种文件头单测 · probe IPC（`npx electron verify-samplerate.js`）
- `index.html` — 桌面版页面，与网页版单文件（[hibiki-player-web](https://github.com/kato-ito/hibiki-player-web) 的 `hibiki-player.html`）同源，界面改动需手工双向同步
- `make-icon.js` — 纯 Node 生成应用图标（深色圆角底 + 绿色声波条），输出到 `build/icon.ico`
- `check-syntax.js` — 提取 html 内联脚本供 `node --check` 做语法检查
- `snap.js` — Electron 打开应用并截取各 UI 状态截图，用于界面验证（`npx electron snap.js`）
- `snap-player-view.js` — 播放界面截图（有歌词 / 无歌词布局）
- `snap-applemusic.js` — v1.9.0 网易云结构 + 界面切换回归验证：底栏/菜单/抽屉结构断言、切回经典后整段声谱/声场仍有内容（亮像素断言）、分析丢失自动补跑（`npx electron snap-applemusic.js`）
- `package.json` — 含 electron-builder 打包配置

## 国内网络注意事项

electron-builder 需要下载 winCodeSign / nsis / nsis-resources 工具包（默认从 GitHub，国内易超时）。
已手动放置到本机缓存：`%LOCALAPPDATA%\electron-builder\Cache\`。换机器构建如遇同样问题，
可从 `https://registry.npmmirror.com/-/binary/electron-builder-binaries/` 手动下载对应版本，
解压到 `Cache\nsis\`、`Cache\winCodeSign\` 下（注意 nsis-resources 也放在 `Cache\nsis\` 内）。

Electron 发行包缓存在 `%LOCALAPPDATA%\electron\Cache`（约 220 MB）。若该缓存被清理，
构建时需设置镜像重新下载（实测可用）：

```bash
ELECTRON_MIRROR="https://cdn.npmmirror.com/binaries/electron/" npx electron-builder --win nsis
```

注意：`registry.npmmirror.com/-binary/electron/` 的老路径已 404，请使用上述 cdn 地址；
构建若中断，可能在后台残留 `app-builder.exe` 进程锁住 `dist\win-unpacked\`，任务管理器结束后再重试。
