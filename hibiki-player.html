    音频基本数据

    🎵 松开鼠标，加入歌单并播放支持 mp3 / wav / ogg / flac / m4a 等常见格式，可拖入多个文件或整个文件夹

    提示：波形/频谱为实时分析（FFT 4096 点，48 kHz 下分辨率 ≈ 11.7 Hz）。频谱与声谱图的频率上限自动跟随音频采样率：44.1 kHz 文件显示到 22.05 kHz、48 kHz 到 24 kHz、96 kHz 到 48 kHz（分析采样率上限 96 kHz，更高的源显示到 48 kHz 并在状态栏标注）。
    声场示波器读法：竖线 = 单声道/居中，两条斜线 = 声像偏左 / 偏右，横线 = 左右反相（ρ 趋近 -1）。
    播放文件时顶部出现播放条：⏸/▶ 暂停与继续，⏮/⏭ 上一首 / 下一首，进度条可随时点击 / 按住拖动调整播放点，右侧滑杆调音量；快捷键：空格 = 播放/暂停，← / → = 快退/快进 5 秒，↑ / ↓ = 音量，M = 静音，N / P = 下一首 / 上一首。音量只影响监听，不影响分析显示。
    歌单：🎵 按钮可多选文件，📂 按钮可选整个文件夹，也可把多个文件 / 文件夹直接拖进页面；点击列表切歌，点击正在播放的曲目 = 暂停 / 继续（⏸/▶ 按钮与空格键同理），× 移除曲目，长按某首并拖动可调整播放顺序，右上角按钮切换 列表循环 / 单曲循环 / 顺序播放 / 随机播放。歌单收藏（桌面版）：➕ 新建歌单后开启「追加导入」，即可把不同文件夹的音频陆续加入同一歌单；需先在歌单中添加歌曲，才能 💾 保存为新歌单，保存后下次打开自动恢复（文件移动/删除会标注缺失），下拉框可随时切换已保存歌单。
    播放界面：主界面为歌单视图（歌单大列表 + 底部迷你播放条，迷你条只显示封面 / 曲名 / 播放控制），点击迷你条任意空白处进入歌曲播放视图（大封面 + 歌词 + 全功能播放条），左上「⌄ 返回歌单」随时返回。设置集中在 ⋯ 菜单（歌单视图在顶栏右侧、播放视图在底栏右侧）。音频数据显示：⋯ 菜单里的「📊 音频数据显示」开关（设置保存在本机）开启后，封面与播放控制移到左半边，右半边显示 波形 / 频谱 / 声谱图 / 声场 四种数据图（页签切换，切换有平滑动画）。播放视图为 Apple Music 风格：大封面（暂停时封面微缩）+ 播放/暂停、⏪/⏩ 快退快进 5 秒、⏮/⏭ 切歌与可点击/拖动的进度条；解析到歌词时右侧同步滚动显示（当前行放大高亮，点击歌词行可跳转播放，滚动鼠标滚轮后暂停自动跟随几秒），无歌词时左侧整体居中显示。封面与标题/歌手自动从 MP3 / FLAC / M4A 标签读取，无标签时按文件名生成渐变占位封面。歌词来源：与音频同名的 .lrc 文件（拖入页面或随 📂 文件夹一起导入时自动配对，桌面版保存歌单会一并记住歌词路径），或点「📃 载入歌词」手动指定当前曲目的 .lrc。
    皮肤：🎨 提供五种界面风格，支持自定义背景图并调节遮罩浓度；设置保存在本机，下次打开自动恢复。
    杜比 / DTS：桌面版内置解码器，可直接播放 AC-3、E-AC-3（DD+）、TrueHD、DTS、WMA 以及内含这些音轨的 MP4 / MKV / MKA（自动转为 PCM，保留原始采样率；网页版无此能力）。多声道输出：工具栏 🔊「杜比输出」为独立开关面板，可选两种杜比输出模式 ——「原生多声道直出」保留 5.1/7.1 原始布局交给系统空间音效/杜比渲染；「重编码适配设备」按输出设备支持的声道布局重新编码（如 7.1 源在 5.1 设备上重编码为 5.1，而非一路降到双声道；设备仅立体声时则为立体声）。想获得杜比全景声效果：Windows 声音设置 → 选择输出设备 → 空间音效 → Dolby Atmos（需安装 Dolby Access）。
    播放立体声文件时后台解码后同时计算整段声谱与声像轨迹，彩色竖线为播放位置；单声道文件声像轨迹为居中直线。
    若浏览器拦截麦克风权限，可在本目录运行 python -m http.server 后访问 http://localhost:8000/hibiki-player.html。
